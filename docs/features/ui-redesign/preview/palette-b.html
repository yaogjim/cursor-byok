取舍要点
  • 01 暖白纸 · 墨绿：已经在这个方向上，绿色同时承担「运行中」和「省钱」两种信号，语义略重；但整体最平衡。

  • 04 中性纸 · 靛蓝：把「价值」交给数字本身，强调色只做导航与运行状态；最不容易看腻，但个性最弱。
