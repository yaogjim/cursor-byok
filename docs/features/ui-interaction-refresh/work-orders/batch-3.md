# 第 3 批工单：请求列表交互

- 授权：用户已确认继续第 3 批，接受本页排序与行详情降级；真实桌面验证暂缓。
- 依据：`../plan.md` §7（含 2026-11-18 补充边界）、`../execution.md` 共同纪律。
- 目标链路：总览请求列表 → 时间范围/筛选 → 当页列排序 → 展开详情；不改变数据获取与服务端分页契约。

## 范围与规则

1. 主改 `frontend/src/components/RequestListPanel.vue`；可新增针对该组件的测试脚本。仅在确实需要时最小调整调用方，不改 Go、appState 数据契约、路由或保存作用域。不新增依赖，不 commit/push，不操作真实账号或重启用户应用。
2. 时间显示：today 为 HH:mm:ss，24h/7d/30d 为 MM-DD HH:mm，使用本地时区、补零，非法/空日期显示 —；保留数值字体。
3. 可排序字段：at/inputTokens/outputTokens/durationMs/ttftMs。每列无→升序→降序→无；切另一列从升序起。对 props 当页数组的副本排序，不修改源数据；相同值保持原次序；缺失或非法数值/日期两方向都放末尾，0 为有效值。无排序恢复服务端原顺序。
4. UI 明示「本页排序」与「翻页保留排序，切换筛选重置」。翻页保留排序字段和方向；range/provider/model/status 变化重置排序；筛选/时间范围/翻页清空展开状态。用语仅限本工单需要的新增提示，不改既有无关文案。
5. 列头用原生 button，箭头表示方向，th 的 aria-sort 为 none/ascending/descending；排序按钮可键盘操作。
6. 行可点击展开，也可聚焦后 Enter/Space 展开折叠；首列放展开按钮并提供 aria-expanded，避免按钮事件冒泡造成双切换。保留表格语义，不用 role=button 覆盖 tr；详情行 colspan 与实际列数一致。使用稳定且不冲突的行身份，不仅依赖日期。
7. 详情完整换行显示错误分类、状态码与状态、请求 ID、原始请求模型、上游模型、缓存读取与写入 token 明细；缺失值显示 —，0 正常显示。不展示不存在的错误全文、不伪造请求内容；不使用 v-html。错误全文登记为 data gap，不作为本批开发阻断。
8. 保留加载、空、错误/重试、分页、summary 的原有行为与事件。

## 实施与验证

- 按 TDD 小步推进，先写关键行为测试并观察 RED，再实现 GREEN。优先真实组件挂载/渲染测试，不只做源码存在断言；不为测试安装依赖。测试需覆盖三态/跨列排序、相同值/缺失/0、不修改 props、时间格式、筛选重置/翻页保持与展开清空。
- 执行 `npm run build`、`node scripts/test-config-projection.mjs`、本批新增回归脚本。前批脚本仅在受影响时复跑。
- 浏览器用合成无敏感请求记录验证：today/30d、耗时升降恢复、跨列、分页保持、筛选重置、鼠标展开和真实键盘 Enter/Space 展开折叠，浅/深两主题截图。明确这是组件/预览合成数据，不是 Wails 真实请求链路。
- 不对真实服务做成功保存、导入或启停，不替换/重启用户应用；浏览器 renderer 异常如实报 env gap，不擅自关闭用户登录标签。
