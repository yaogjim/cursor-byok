# Gateway-byok v0.060.0

本版本完成 main → gateway 价值功能迁移（`main-gateway-value-migration-20260907`，行为合同 `docs/main_gateway_价值功能分析与迁移方案_20260907.md`）：provider 溢出有界恢复、CLI 本地模型目录与凭据隔离、Shell/Bash 全链兼容、WebFetch 直连安全、共享工具结果预算与 Cursor 正常重启；包含两轮完成情况复审（review-r1～r4、CURSOR-1）确认的缺陷修复。交付状态 `verified-partial`：定向回归通过，最终全量/race/build/打包及真实 CLI/Cursor/代理验收按用户授权省略。

## Provider 溢出有界恢复（Stage 1，REC/CMP）

- 溢出分类：可信 provider overflow 分类接入 adapter，保持 HTTP/fallback 重试语义，排除普通错误/取消；只有明确溢出保留非 retryable overflow terminal（修复 review-r3：compiler/storage/usage 失败保留原类别，不再误标为 overflow）。
- 压缩预算：比例 reserve、完整摘要请求预算、完整轮次裁剪及一次本地 fallback 接线；每 Run 一次恢复、当前调用输出门禁、旧事件隔离与 RunSSE 合成链落地；typed terminal code 保留 usage_persistence_error。
- 回归覆盖：溢出/压缩/handler 定向测试、合成 provider 经实际 `Service.RunSSE` 订阅入口的恢复、再次溢出唯一 terminal、延迟 Blob ACK、取消/旧事件、独立 usage 与历史保留。

## CLI 本地模型目录与凭据隔离（Stage 2，CLI/MODEL）

- 四路径（Codex/Grok/官方目录等）共用 builder/policy；目录固定哨兵、optional baseUrl 未设置时保留官方端点。
- 新增 Codex/Grok 从目录 ID 到运行时凭据 resolver/合成 provider 的实际 HTTP 合成链测试；CLI 目录与运行时共享 manager/channel ID 事实源，请求时解析凭据，目录不落凭据缓存。

## Shell/Bash 全链兼容与共享工具预算（Stage 3/5，TOOL/RESULT）

- 新增 `agent/core.CanonicalToolName`：在 known-tool/权限判定之前及 started/bridge/evidence/replay/truncation 各边界统一 Shell/shell/Bash/bash 四名称；工具目录仍仅发布 Shell，存量磁盘历史不重写、不重派发。
- 新增共享预算包 `internal/backend/agent/toolresult`：收敛 UTF-8 截断、bytes/items 提示与额度；迁移展示及历史回放改为薄调用层，保留 Shell 分字段、图片回放省略、资源结构与 edit 错误差异；exec/interaction/projector 的重复计算移除。
- 冻结样本、UTF-8/幂等与四名称旧历史定向测试通过。

## WebFetch 直连安全（Stage 4，FETCH）

- 直连固定已验证 DNS 地址，redirect 逐跳代理选择。
- 修复 review-r1：`fec0::1`、`::2`、`4000::1` 等非公网/特殊用途 IPv6 目标现被拒绝，固定公网/特殊用途判断用于所有目标边界。
- 修复 review-r2：仅 IPv4-mapped 等价地址 unmap；内嵌 IPv4 仅用于附加风险检查，6to4/NAT64 保持原 IPv6 拨号目标；补 HTTPS Host/SNI、解析结果/拨号一致性 fixture。

## Cursor 正常重启（Stage 6，CURSOR）

- macOS 已识别 bundle 的一次确认、正常退出总时限、被改键快照与失败回退接入真实 StartProxy/Wails/UI；确认后顺序 Quit→Inject→Settings→Launch；只取消辅助命令，不强杀 Cursor；启动等待实际命令结果且只发一次；并发 start 返回 busy；托盘显式启动进入主窗口同一确认流程；自动启动需确认时显示 LastError、保持原状态且不自动弹窗；回滚/重启失败可见，已有共享 backend/MITM 不停止。
- Windows/Linux 未实现检测/正常退出时提示手动处理，不虚报未运行（保留 feature-gap）。
- 复审修复（CURSOR-1）：`Restore` 增加 owner 与旧值/目标值核对，跨实例/同 owner 新值不再被旧快照回滚；`ApplyPlanned` 在同一所有权锁内核对计划并写入；`StartProxy` 传递同一快照，CA 后不另建计划；owner 读取错误与内层回滚错误对外可见；状态事件保留失败信息（部分成功 `cursor_launch_partial` 不再被清空）；`InspectCursorProxyStart` 改 TryLock 返回统一 busy 错误。
