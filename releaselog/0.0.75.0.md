# Gateway-byok v0.0.75.0

本版本交付「官方/BYOK 混用兼容」第一阶段切片：Task 子代理模型参数快照保留、导入会话已预取原生文本/工具历史读取、投影交错工具批次合并修复及失败保全收口。整体混用功能保持 planned，已实施切片为 `verified-partial`（隔离协议链验证完成；缺失 Blob 异步读取、原生检查点写出、同会话增量同步与真实 Cursor/官方端到端验收待后续）。设计锚点为系统 Design §19.3a/§19.3b/§19.4b。

## 功能内容

### 子代理模型参数快照（C0-P1）

- `SubagentModelOverrideSelection` 新增 `Parameters` 字段，保留原始参数序列与 protobuf 未知字段，不再仅依赖数量推断最终参数。
- lookup/clone 均返回参数切片及参数对象独立的深拷贝快照，避免运行期共享可变状态；`handleToolInvocation` 读取覆盖表时加锁保护。

### 原生文本历史读取（C0-H1）

- 导入会话解析已校验 SHA-256 的 root 引用，接通原生 user/assistant 字符串消息，保持顺序与重复实例；完整 root 优先于 turns，不重复拼接。
- 保留旧内联读取与全部 root 缺失时的 turns 回退；部分缺失、混合格式、损坏或不支持的数组内容明确失败。
- 全部输入解码与 entry 编码成功后才更新会话元数据（token 用量、回合引用、下一回合编号），失败不留下半份导入。

### 原生工具历史读取（§19.3b 输入切片）

- 实现 text/tool-call/tool-result 内容转换与工具批次校验；参数与结构化结果保留原始 JSON 和大整数，字符串结果保留原文本。
- 未知或不可表达内容明确失败，不裁块继续；失败请求不调用模型且原持久会话逐字段不变。
- 投影合并修复：完整单批次不再重排工具结果；已有结果后仅凭实际非空模型调用身份合并交错片段，修复分组 ID 误合并导致的结果重排与重复批次丢失。

### 永久回归补强

- 未知消息/内容字段、错误角色/载荷、工具缺失/失配/重复、根引用部分缺失/混合、SHA-256 校验及后段 plan/todo 解码错误均有失败原因/阶段断言。
- 失败保全验证接到真实 Connect HTTP BidiAppend 入口，防止任意提前错误掩盖待测行为。

## 实现要点

- `agent/core/types.go`：`Parameters` 字段与 `Clone()` 深拷贝；`LookupSubagentModelOverride` 返回独立快照。
- `forwarder/token_usage.go`：`resolveImportedRootMessages` 区分原生 root 与旧内联格式；元数据更新移至全部编码成功后。
- `forwarder/imported_blobs.go`：原生消息解码、text/tool-call/tool-result 转换与批次校验。
- `forwarder/projector.go`：`coalesceProjectedInterleavedReplayToolBatches` 按实际调用身份合并交错片段。
- `forwarder/service.go`：覆盖表解析保留参数序列，克隆与读取加锁。
- 不新增依赖、模型 schema、协议或持久化字段。

## 验证（verified-partial）

- 已预取文本/工具输入、参数快照、投影合并均为 RED→GREEN 永久回归；HTTP BidiAppend→导入/保存→真实 PromptCompiler/provider gateway→模拟模型请求验证完整工具历史、结果顺序和参数精度。
- 独立复审发现分组 ID 触发结果重排与重复批次合并缺陷，主会话补回归修复后复审关闭。
- 隔离 HOME、固定 Go 缓存、禁依赖下载：`go test ./internal/backend/agent/core ./internal/backend/agent/bridge/exec ./internal/backend/agent/prompt ./internal/backend/forwarder -count=1`、历史/投影/参数定向 `-race`、四包 `go vet`、gofmt 及 `git diff --check` 全批通过（`NATIVE_TOOLS_REVIEWED_VALIDATION_PASS`、`MIXED_COMPLETION_FINAL_REVIEW_PASS`）。
- 本版仅编译 macOS arm64 宿主平台分发包（`task build`），Windows/Linux 未编译。
