# Gateway-byok v0.0.61.1

本版本完成「重开确认、订阅状态与模型代理回归修复」：修复退出 BYOK 后重开再次要求确认并重启 Cursor 的问题、订阅账号激活/健康状态展示与刷新交互缺陷，以及模型列表刷新丢失自定义出站代理的问题，并包含构建扫描将测试示例账号收进翻译资源的修复。交付状态 `verified-partial`：五包完整 Go 测试与 vet、十项前端测试、配置投影、54 调用点日志契约与生产构建通过；真实 Wails、Cursor 正常重启/钥匙串授权与用户真实 7890 代理测速失败仍未实机复现。

## 重开不再重复确认（restart）

- 需求锚点：工作决策基线 §10.14「Cursor 启动与重启」（2026-09-08 用户确认）；设计锚点：系统架构 §6.0。
- 根因：`doShutdownForQuit` 退出时清除 settings.json，下一次 `Plan.NeedsChange` 因键缺失而再次要求确认并重启 Cursor。
- 修复：正常退出只暂停服务并保留已应用的 Cursor 代理设置、owner 文件及 `NODE_EXTRA_CA_CERTS`；重开时配置一致则免确认直接接管。首次接入或设置真实变化仍走确认与正常重启；显式「停止服务」仍是断开动作，只清理本实例成功接管后的配置。
- 用户已接受暂停期间本地代理不可用；彻底断开须在成功启动接管后显式停止。
- Darwin CA 环境清理增加可注入替身（`clearSystemNodeExtraCACertsFn`），隔离测试不再调用真实 launchctl。

## 订阅账号状态（accounts）

- 面板独立展示当前激活账号与健康状态（ready/auth_required/quota），不再用禁用按钮承载状态；激活标记与授权/配额可用性分别展示。
- 刷新失败后允许再次点击重试，错误保留展示，成功后清除；刷新失败不将网络错误当作账号授权失效。
- 成功激活后列表与页脚一致同步；provider 切换增加响应代数保护，旧 provider 响应不覆盖新列表。
- 新增 `frontend/src/state/subscriptionAccounts.js` 状态 helper 并接入真实 Vue 模板；camelCase 为正式 AccountStatus DTO，PascalCase 仅测试兼容。
- 验证（隔离浏览器、合成账号、stub API）：三账号当前异常标记、两次刷新（先失败后成功）、busy 禁用/恢复、切换激活及页脚，无 console 错误或禁用调用。

## 模型代理回归（proxy）

- 修复 `FetchModelAdapterModels` 在凭据 Resolve 前未挂 `OutboundProxy`：订阅 token 刷新此前使用默认代理；补 `WithRequestConfig` 后模型发现链路与模型自定义代理一致。
- 新增 `TestModelAdapter` 成功链路回归：真实入口、过期合成 JWT、本地 HTTP CONNECT 代理与 TLS 假上游，断言刷新后的 token 用于推理、结果 `success`、模型代理两个目标 host 命中且 env 代理零命中。
