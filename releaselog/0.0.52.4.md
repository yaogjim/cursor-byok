# Gateway-byok v0.0.52.4

本版本完善 Gateway 卡片可用性，并收紧 managed Codex 请求体边界。保留 Codex 多账户、sub2api 导入与订阅认证全部能力。

- Gateway 接入卡片新增「测试可用性」：启动 Gateway 后自动执行一次本机 HTTP 探测，验证监听、鉴权与 `/v1/models` 模型列表接口，实时显示入口状态、公开模型数量与延迟；也可手动点击重测。
- Gateway token 复制与轮换改用 Wails 原生剪贴板 API 并等待写入结果，失败时给出可读错误；轮换后新 token 自动复制。
- Gateway 卡片补充「极简使用」引导，按启用并保存 → 启动 Gateway → 填入 Base URL 与 Token → 填写公开别名的顺序说明。
- managed Codex 请求体白名单不再透传 `previous_response_id`（该 ID 与签发它的 ChatGPT 账号绑定，托管场景无法验证归属，fail-closed）；static OpenAI Responses 保持原请求体不变。
- 保留：Codex 多账户池与 401 定向刷新/配额幂等轮换、sub2api JSON 多选导入、Codex/Grok 官方上游固定归一化、接入中心分区布局。

验证：订阅认证、模型路由、配置投影与前端生产构建通过；Apple Silicon macOS DMG 已通过版本、arm64 架构、codesign、`hdiutil verify` 与 SHA-256 校验。未使用真实订阅 token 请求外部上游，未执行 Wails 窗口点击。
