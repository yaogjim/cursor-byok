# Cursor助手 v0.0.49.3

本版本完善 Agent 执行证据、完成门禁与历史回放治理，并进一步收紧公共 transcript 的隐私边界。

- 为新 history 持久化可选 `ModelCallID`，按同一模型调用聚合 reasoning，并将 provider signature 与原始 reasoning 正文精确绑定；旧 history 继续兼容读取。
- 新增 metadata-only 执行证据账本，只依据结构化工具调用和已进入终态的工具结果判断 mutation 与 verification，不记录 stdout、文件正文、reasoning、凭据或完整工具参数。
- 编辑完成必须同时具备成功 mutation，以及晚于最后一次 mutation 的成功 verification；mutation 后已有 verification 自动失效。
- 证据不足时最多注入一次结构化 reminder 并续跑一次，重启恢复保持幂等；再次不足时保守收口，避免无限循环。
- Agent 与 Subagent prompt 明确要求使用结构化工具证据，assistant 自然语言声明不能替代实际修改和验证。
- 回合诊断与 debug recorder 采用 metadata 白名单；reasoning 仅保留稳定 hash，解析异常时按隐私优先原则关闭输出。
- 公共 transcript 仅保留用户可见文本和合法结构化工具事件，不投影 reasoning、signature、回放数据、内部 reminder 或诊断 metadata。
- 新增 15K reasoning canary 与门禁 reminder 隔离回归，验证超长 reasoning 和内部控制信息不会泄漏到公共 transcript。
- 对缺少模型调用身份的裸 `Message` 二次 normalize，以及双方身份均为空的旧连续工具批次，保持保守兼容行为，不跨调用搬移 reasoning。
