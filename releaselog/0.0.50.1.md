# Gateway-byok v0.0.50.1

本版本完成 v5 四页控制面、真实接入状态与使用统计能力，并修复发布前代码复审发现的主题、路由脏状态、模型配置文案和 Windows Cursor 启动隔离问题。

- 主导航重构为「总览 / 接入 / 模型 / 设置」四页；`/access` 支持 Gateway、Cursor、Codex 和 Claude Code 客户端入口，并保留旧路由兼容重定向。
- 接入页采用 master-detail；Cursor 与 Gateway 保持真实独立配置作用域、保存和生命周期，Codex/Claude Code 在真实授权合同完成前显示 unsupported 状态。
- 总览页使用持久化 usage 小时桶提供 `24h` 数据，`30d/all` 使用日桶；无历史小时数据时显示真实空态，不从 recent events 或 fixture 补造统计。
- 主题支持浅色、深色和跟随系统；系统主题会随操作系统外观变化更新界面和原生窗口背景。
- Cursor 启动使用真实 `LaunchCursor`；Windows 启动进程使用独立进程组，避免依附助手进程。页面不使用 stop/start 模拟重启。
- 模型页支持真实模型计数、提供商筛选、搜索、列表/栅格、排序、编辑、测试、复制、删除、批量测试取消和完整配置导入导出。
- 设置页提供基本设置、会话与日志、网络与请求、数据与恢复四段面板；计划中功能保持禁用且不调用后端。
- 接入离开确认会检查 Cursor/Gateway 脏状态并集；模型导入导出按钮明确标示为完整配置。
- Codex/Claude Code 真实授权、续期、配置同步和 ACP 端到端验收仍需独立后端合同与 Design Gate，不作为本版本已完成能力。

验证：前端路由/指标/配置投影测试、`go test ./... -count=1`、`go vet ./...` 和生产构建通过；Wails 视觉验收仍受本机环境限制。
