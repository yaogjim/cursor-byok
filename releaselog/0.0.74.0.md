# Gateway-byok v0.0.74.0

本版本完成「模型启停与共享入口默认公开」：模型列表支持逐个启用/停用（停用影响 Cursor 等全部调用入口，而非仅界面隐藏），共享入口 Gateway 的公开模型列表默认包含全部已启用模型并按模型名公开，支持单独改公开名或取消公开。产品条款已同步工作决策基线 §10.10 与系统 Design §14.11.3a。交付状态 `verified-partial`：实现、隔离测试与合成数据浏览器检查已完成；真实 Wails 配置保存/重载及 Cursor/OpenAI 客户端实机验收待后续部署窗口。

## 功能内容

### 模型启停

- 配置层新增 `modelAdapters[].enabled`（缺失即启用，显式 `false` 为停用）；旧配置无该字段时全部视为启用，不做迁移脚本。
- 模型列表与模型编辑页可切换启用/停用；停用模型在 Cursor/CLI 目录与默认选择中不再出现，显式旧 ID 命中停用项时拒绝调用（不回落到其他模型），自动选择跳到首个可用模型，全部不可用时明确失败。
- fallback 计划跳过停用渠道：alias 停用时失败，primary/candidate 停用时从实际计划移除；不把停用渠道发送到上游。

### 共享入口默认公开

- Gateway 公开模型从"仅显式映射"改为"默认全量公开"：所有启用且未显式取消公开的模型默认按模型列表名称公开；旧的自定义公开名继续保留优先。
- 共享入口可逐行修改公开名或取消公开（opt-out），取消公开不影响模型经 Cursor 等其他入口使用；停用模型不参与公开，重新启用后按原偏好恢复。
- 默认名冲突或与既有自定义名冲突时，仅冲突项自动加模型 ID 稳定短后缀，未冲突项保持原名；取消原 32 项硬上限实现全量默认公开；超长公开名截断改为显式校验（最大 128 字节）而非静默截断。
- Gateway Chat/Responses 请求与 `/v1/models` 使用同一公开解析；取消公开或停用后旧公开 ID 不可调用。loopback/Bearer/token 安全边界不变。

## 实现要点

- `config/types.go`：`ModelAdapterConfig` 新增 `Enabled *bool`（不参与渠道 ID/分组哈希）；`MaxGatewayPublicModels`(32) 替换为 `MaxGatewayPublicModelIDLength`(128)。
- `config/gateway.go`：公开模型解析支持默认派生（启用+未取消公开）、显式自定义名与显式不公开状态，冲突后缀保证唯一。
- `config/resolver.go`、`runtime/local_runtime.go`、upstream 消费方接线停用过滤与旧 ID 拒绝。
- 前端 `configProjection.js`、`GatewayCard.vue`、`ModelConfig.vue`、`ModelEditor.vue`、`appState.js` 增加启停与公开行编辑；i18n 四语言（zh-CN/en-US/ja-JP/ru-RU）同步。
- 删除模型时同步清理该目标的公开偏好，不留失效映射阻断模型页保存。
