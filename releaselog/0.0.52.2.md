# Gateway-byok v0.0.52.2

本版本完成 Codex 与 Grok 订阅认证接入，并保留此前的模型管理和 Provider 中断恢复能力。

- Codex 支持设备码授权、`auth.json` 导入和 sub2api JSON 多选导入；sub2api 候选按当前接入类型过滤，不会把其他订阅类型导入 Codex 账号池，且源文件保持只读。
- Grok 支持设备码授权和 sub2api JSON 多选导入；只接受 Grok/xAI OAuth 账号。
- Codex 逐账户用量刷新通过公开 Wails 桥接调用，并继续按实际账户写回双窗口用量。
- Cursor backend 与独立 Gateway 共用 managed credential resolver；Codex 401 仅在安全窗口刷新并有限重试。
- 接入中心将 Codex 与 Grok 授权、账号和用量分别放入对应配置区域，顺序为 Gateway、Cursor、Codex、Grok、Anthropic。
- 修复订阅模型测试沿用用户填写接口地址的问题：Codex 订阅固定使用 ChatGPT Codex Responses 官方上游，Grok 订阅固定使用 xAI 官方上游；订阅模式下接口地址与协议端点只读。
- 补齐 Codex usage/session 持久化与展示、设备授权终态清理、Grok 耗尽账号过滤和能力令牌脱敏。
- 保留模型身份 remap、Provider 中断恢复、错误传播和浅色默认主题。

验证：Codex 多账户存储与轮换、模型路由、后端配置投影、前端配置投影和生产构建通过；Apple Silicon macOS DMG 已通过版本、arm64 架构、codesign、`hdiutil verify` 与 SHA-256 校验。未使用真实 Codex token 请求外部上游，未执行 Wails 窗口点击。
