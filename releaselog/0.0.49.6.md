# Cursor助手 v0.0.49.6

本版本修复 Provider fallback 共享 attempt 预算的渠道覆盖问题，并完善五物理渠道配置与测试交互。

- fallback 先为后续兼容渠道各预留 1 次 HTTP attempt，再用剩余预算重试当前渠道：3 渠道/5 attempts 为 `3+1+1`，5 渠道/5 attempts 为 `1+1+1+1+1`，5 渠道/9 attempts 为 `3+3+1+1+1`。
- fallback 链最多支持 1 个主渠道和 4 个有序物理候选渠道；预算不足时按配置顺序覆盖到预算耗尽，仍保持单渠道最多 3 次及共享总预算门禁。
- “测试全部”静默跳过逻辑 alias，单独测试逻辑 alias 保留实际运行验证提示；长下拉列表支持正确滚动和键盘访问。
- 同时包含 0.0.49.5 的多层模型路由、配置写入事务、可选物理上游容量保护和独立 CLI 模型池能力。
- 已知边界：真实 `grok-HA` 未启用容量限制；CLI 两模型故障切换和 Wails 浏览器视觉验收仍未闭合，不作为本版本已完成能力。
