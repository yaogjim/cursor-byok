# Gateway-byok v0.0.57.0

本版本完成 BYOK 预算化恢复：网关在单一 Cursor Run/Agent 生命周期内吸收上游瞬时故障（500/503、transport reset、超时），按模型级预算做同渠道重试与有序候选渠道切换；任意输出或副作用出现后禁止重放，耗尽预算后至多向 Cursor 投影一次 terminal（`IsRetryable=false`）。同时落地 OpenAI Responses 原生图片生成门禁。全局 `providerStreamIdleTimeout` 双路径被删除，不保留兼容层。

## 统一恢复策略与 typed 错误分类

- 新增 `provider_failure.go`：唯一 typed 分类入口，按类别/原因/阶段/HTTP status 区分 DNS、TCP、TLS、headers、首事件、流读取；网关自建 liveness 超时使用独立 typed error，不会被误判为用户取消。
- 新增 `recovery_policy.go`：分类 + 安全快照 + 共享预算 → retry / switch / fail 决策矩阵。HTTP 500/502/503/504/524、可恢复 transport、TLS handshake EOF、建连/首事件超时：同渠道最多 2 次后可安全切换。429 遵守可容纳于剩余预算的 `Retry-After`，否则跳过等待直接切换。401 只走凭据刷新/账号轮换。403/其他 4xx/529/父取消/证书校验失败/永久 DNS/请求构建/协议解析/provider terminal 快速失败，不切渠道。
- `retry.go` 与 `fallback_router.go` 改为纯执行策略决定，不再各自判断状态码；账号刷新、quota 轮换、零字节恢复消费同一 HTTP attempt 预算，无嵌套放大。

## 共享预算与四阶段活性

- `FallbackRetryBudget` 同时约束全链 attempts（默认 5，范围 2–9）、每渠道 attempts（默认 2，范围 1–3）、累计退避 sleep（默认 8s，范围 1–30s）与候选数（最多 1 primary + 4 candidates）。`maxWaitSeconds` 只累计实际退避 sleep，不含模型推理、首 Token 等待或渠道执行时间；退避期间整呼时钟暂停。
- 新增 `liveness.go` 替代被删除的 `stream_idle.go`：建连（默认 30s，5–120）、首事件（默认 600s，60–1800）、流空闲（默认 240s，30–900）、完整逻辑调用（默认 7200s，900–21600）四阶段独立计时。首事件阈值保证 90 秒以上正常首 Token 不被误杀；所有计时器在成功/失败/取消/body close 时停止，无 goroutine 泄漏。

## 安全门与单一 Cursor 生命周期

- 安全门：任意 raw byte、模型事件、工具进度或副作用出现后立即关闭重试/切换窗口；部分输出不重放（partial-output continuation 明确排除）。
- Cursor 只选择一个逻辑模型；网关在原 `request_id`/`run_id`/`model_call_id` 内完成内部恢复，成功后继续原 RunSSE；全部耗尽只发一次 terminal provider error。
- 候选渠道契约：必须同 adapter 类型与 endpoint family，前后端均拒绝跨协议混排、自引用、重复、悬空与能力降级。

## 模型级恢复配置与 UI

- `providerFallback` 增加 `maxAttemptsPerChannel` 与四项活性阈值字段；resolver 将完整 RecoverySettings 注入 ChannelPlan，单渠道计划同样注入 liveness。
- 删除全局 `providerStreamIdleTimeout` 配置、resolver 与写回路径，重新保存后只写模型级结构。
- `ModelEditor.vue` 在同一模型编辑区配置候选顺序、每渠道次数、累计退避与四项活性阈值；`configProjection.js` 与后端共享默认值/范围/兼容校验。

## 结构化恢复观测

- 每次失败记录 failure_category/cause/phase/http_status、逻辑模型、渠道顺序、渠道内/全链 attempt、已用/剩余退避、选定动作、切换目标或抑制原因、安全门与最终结果；延续 `provider_response`、`provider_fallback_attempt`、`provider_stream_finished` 关联链。
- 日志不落 API key、Authorization、自定义 header、完整 URL/query、请求/响应正文与账号标识；trace 扫描确认敏感值命中为 0。

## OpenAI Responses 原生图片生成门禁

- 模型适配器新增 `openAIImageGenerationEnabled`，仅允许 openai 适配器、static 凭据且 `/v1/responses` 端点开启；切换类型/端点/凭据后自动关闭。
- Responses 请求仅在用户请求命中 GenerateImage 工具且文本呈现图片意图时注入原生 `image_generation` 工具；Chat Completions 路径统一剥离 `image_generation` 工具与历史 `image_generation_call` 输出项，防止不兼容端点 400。
