# Gateway-byok v0.0.52.1

本版本完成 Codex 与 Grok 订阅认证接入，并保留此前的模型管理和 Provider 中断恢复能力。

- Codex 支持设备码授权和 `auth.json` 导入/恢复，凭据保存为应用私有副本，不修改源文件。
- Grok 支持设备码授权、账号管理、usage 查询和同 provider 额度轮换。
- Cursor backend 与独立 Gateway 共用 managed credential resolver；Codex 401 仅在安全窗口刷新并有限重试。
- 接入中心将 Codex 与 Grok 授权、账号和用量分别放入对应配置区域，顺序为 Gateway、Cursor、Codex、Grok、Anthropic。
- 补齐 Codex usage/session 持久化与展示、设备授权终态清理、Grok 耗尽账号过滤和能力令牌脱敏。
- 保留模型身份 remap、Provider 中断恢复、错误传播和浅色默认主题。

验证：订阅认证相关 Go 回归、除外部 OpenCode 环境烟测外的 internal 回归、Go vet、前端生产构建、配置投影和接入路由测试通过。race 的 forwarder 包因本机 Go 编译大型生成文件耗时异常未取得完整结果。
