# Gateway-byok v0.0.50.3

本版本对齐 Codex/Claude Code 接入详情与模型管理的确认 UI，并修复模型页保存身份变更。

- 接入中心 Codex 使用 OpenAI 品牌图标，Claude Code 使用 Anthropic 品牌图标与品牌橙色。
- Codex/Claude Code 接入详情采用授权管理布局；因真实授权 API 尚未接通，展示 0 账号空态「暂无授权账号」，授权/同步/测试/保存按钮保持禁用，且不写入演示账号。
- 模型管理页提供商筛选、彩色提供商标识、无图标的导入/导出、清除全部确认和精简操作菜单；继续使用真实模型数据与既有测试、编辑、保存能力。
- 模型保存按旧渠道 ID 精确 remap fallback 引用；删除/新增不自动配对；OpenAI/Anthropic 类型切换保留 modelID。
- 保留 v0.0.50.2 的 Provider 中断恢复与错误传播能力；浅色仍为新配置默认主题。

验证：前端生产构建、配置投影测试与接入路由测试通过。Codex/Claude 真实授权和 Wails 窗口视觉点击仍为证据缺口。
