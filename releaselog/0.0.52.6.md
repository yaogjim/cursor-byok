# Gateway-byok v0.0.52.6

本版本修复 OpenAI Responses 已收到合法完成终态后仍继续读取 Provider 连接、并被后续传输关闭错误覆盖为失败的问题。

- 完成终态立即收口：成功处理 `response.completed` 的最终文本、usage、reasoning 和工具投影后，立即退出 SSE 读取并进入既有统一收尾，不再依赖后续 `[DONE]`、EOF 或连接关闭。
- 终态优先级修正：合法 `response.completed` 后发生的 `unexpected_eof` 不再覆盖成功；无合法终态的 EOF 仍保持 `StreamTruncatedError`，failed/cancelled/incomplete 和未知终态分类保持不变。
- 单次发布回归：新增确定性 fixture，覆盖终态后 `io.ErrUnexpectedEOF`、Provider 连接持续打开、最终工具调用和 `TurnFinished` 只发布一次。
- 范围边界：独立 HTTP 502 保持既有三次 attempt 边界；本版本不扩大重试、不执行 Transport A/B，也不调整部分流恢复策略。
- 保留 v0.0.52.5 的共享 Provider 流观测、零输出安全恢复、Provider Transport 单变量实验、Gateway 可用性测试、Codex 多账户与订阅认证能力。

验证：`go test -count=1 ./internal/backend/agent/model`、`go vet ./internal/backend/agent/model` 与 `git diff --check` 通过；定向回归确认完成终态不再等待 Provider 连接关闭。未执行真实网络 Transport A/B、未调整 502 重试策略、未构建或发布安装包。
