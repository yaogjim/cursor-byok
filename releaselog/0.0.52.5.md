# Gateway-byok v0.0.52.5

本版本完成共享 Provider 流截断的第一阶段治理，并保留 Gateway 可用性测试、Codex 多账户与订阅认证全部能力。

- Provider 流终态收口：OpenAI Responses 支持 CRLF、空行事件边界、多行 `data:` 与最后事件后直接 EOF；`[DONE]`/`response.completed`、Anthropic `message_stop` 为成功终态，failed/cancelled/incomplete/显式 error 为独立协议终态，无合法终态标记的 EOF 保持截断错误。
- 零输出安全恢复：只有零 provider 字节且零 `ModelEvent`，并属于 typed EOF/unexpected EOF/TCP reset/HTTP/2 reset/GOAWAY 白名单时，才在同渠道预算内最多新增一次请求；读到任意字节或事件后禁止原请求重放，4xx、认证/配额、语法错误、取消和明确协议终态不重试。
- 最终 attempt 观测：记录协议版本、Content-Encoding/自动解压、连接复用与 idle、原始字节数、首末字节、底层 typed error、最后 SSE 事件类型、response ID 短哈希与累计零字节恢复次数；不记录正文、工具参数或 Authorization。
- Provider Transport 单变量实验：新增环境变量 `CURSOR_BYOK_PROVIDER_TRANSPORT_PROFILE`，支持 `auto`（默认）、`http1`、`no_compression`、`fresh_connection`、`direct`，未知或组合值 fail-closed 回到 `auto`；`direct` 只绕过显式 HTTP/SOCKS 代理，不能绕过操作系统 TUN。
- continuation 保持默认关闭：既有 checkpoint continuation 的开关、单次预算和工具/副作用门禁不变，本轮只增加“非瞬时截断错误禁止续写”。
- 保留：Gateway 可用性测试与 token 复制/轮换、managed Codex 请求体白名单（fail-closed 剥离 `previous_response_id`）、Codex 多账户池与 401 定向刷新/配额幂等轮换、sub2api JSON 多选导入、接入中心分区布局。

验证：netproxy/model/forwarder 定向回归、`go test -count=1 ./internal/netproxy ./internal/backend/...`、`go vet ./internal/...` 与 `git diff --check` 通过；确定性 fixture 覆盖 completed-at-EOF、failed/cancelled/incomplete、CRLF/多行 data、缺失终态、plain/unexpected EOF、TCP reset、HTTP/2 reset/GOAWAY、一次上限、raw bytes/model event/取消/4xx 抑制与 HTTP/1 实际协商。Apple Silicon macOS DMG 已通过版本、arm64 架构、codesign、`hdiutil verify` 与 SHA-256 校验。未做真实网络单变量采样、Cursor→Gateway 边界故障注入与 Wails 窗口点击，未使用真实订阅 token 请求外部上游。
