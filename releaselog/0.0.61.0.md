# Gateway-byok v0.0.61.0

本版本完成「模型导入、全部测试与分层出站代理」（需求锚点：工作决策基线 §10.14；设计锚点：系统架构 §14.19 `DESIGN-MODEL-IMPORT-PROXY-001`）：模型专用 YAML 导入→合并草稿→模型分区保存、全量物理模型测试、默认关闭的全局/模型自定义出站代理，并包含整合验证中修复的四个缺陷。交付状态 `verified-partial`：九个相关 Go 包完整测试、前端契约脚本、`npm run build` 与隔离浏览器验证通过；真实 Wails 文件对话框与外部代理实机验收未完成。

## 模型导入（model-import）

- 新增 `ReadModelAdaptersForImport`：服务运行中导入不再被静默禁用；只读取现有 YAML 的 `modelAdapters`，合并到模型草稿，显式保存后才写模型分区。
- 合并策略：先按渠道身份、再按唯一同名更新；保留当前未命中模型及其位置，新增项追加；导入 fallback 引用按导入 ID→当前草稿 ID 重写。失败/取消不改草稿；导入对话框阶段即防重复（busy 提前到入口）。
- 修复导出 ID 缺失：模型 `ID` 标记 `yaml:"-"` 不导出，原读取返回空 ID 无法映射候选引用；复用 `NormalizeModelAdapterDrafts` 恢复派生 ID，跨模型引用校验延至合并后，允许导入引用当前模型的部分 alias。

## 全部测试（test-all）

- 「清除全部」按钮替换为「全部测试」：忽略搜索/提供商筛选，对全部草稿快照调度测试；沿用并发 10、现有单模型接口、逐项结果与超时。
- 单项失败继续；停止只停止后续派发并等待在途结束；空列表/全逻辑 alias 有明确提示。

## 分层出站代理（layered-proxy）

- 根配置及模型级 `outboundProxy` 默认关闭，关闭保留地址。优先级：模型自定义 > BYOK 全局自定义 > 环境/OS > 直连；自定义代理失败不降级默认代理；回环/内部通信保持直连。
- 接通配置规范化、分区保存、设置/模型编辑 UI、全局热更新、请求级覆盖、普通推理、候选渠道切换（liveness/retry/fallback）、模型测试、模型发现及共用 netproxy 出站客户端；不修改系统代理或其他进程代理。
- 修复候选请求丢代理：fallback 候选共用 liveness context，HTTP retry 再替换 context 会丢失请求级代理；在两个 context 边界保留代理后，候选各用自己的代理。
- 修复已保存全局代理快照陈旧：应用持久配置时先更新响应式快照；前端哈希与继承说明使用已保存值而非未保存草稿；仅模型重载时也更新；旧测试结果正确标记需重测。

- 主控 `go test -count=1 -timeout=180s` 覆盖 `internal/netproxy`、`internal/backend/server/config`、`internal/runtime`、`internal/backend/agent/model`、`internal/client`、`internal/backend/agent/bridge/interaction`、`internal/backend`、`internal/app`、`internal/bridge` 九包均退出 0；本地 HTTP/SOCKS5 代理、优先级、失败不降级、并发隔离、热更新/在途请求及网页抓取原有 DNS/私网规则覆盖。
- 最终导入修正后 config/client/bridge 三包再验证通过；补充实际 YAML 导出→读回及部分 alias 用例。`go vet`（config/client）、`node frontend/scripts/test-config-projection.mjs`、`node frontend/scripts/test-client-api-logging.mjs`（54 call sites）、`npm run build --prefix frontend`（134 modules）、`git diff --check` 均通过。
- 浏览器验证（隔离 Vite、合成内存数据）：代理开关/草稿/非法代理提示（`ftp://` 被拒）、全部测试调度（filtered=1,total=2,completed=2）、模型代理继承与关闭保留地址，无未捕获 JS 异常。
